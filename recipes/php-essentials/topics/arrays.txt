Working with lists, PHP arrays

An array holds many values in one variable. A list, $fruits = ['apple', 'pear'];, is numbered from 0, so $fruits[0] is apple. A keyed array, $user = ['name' => 'Ana', 'age' => 31];, is read by name, $user['name'].

Add to the end of a list with $fruits[] = 'plum'; and set a key with $user['city'] = 'Lima';. Remove an entry with unset($user['age']);.

count($fruits) gives the number of entries. in_array('pear', $fruits, true) says whether a value is there, and the true makes it compare the type as well, so the string "1" does not match the number 1. array_key_exists('name', $user) says whether a key exists.

Go through every entry with foreach. foreach ($fruits as $fruit) { echo $fruit; } gives each value, and foreach ($user as $key => $value) { ... } gives the key as well.

Sorting changes the array itself and returns true, not a sorted copy. sort and rsort sort a list and renumber it. asort and arsort sort by value and keep the keys. ksort sorts by key. usort($people, fn($a, $b) => $a['age'] <=> $b['age']); sorts with your own rule.

array_map applies a function to every entry and array_filter keeps the entries a function accepts. Both return a new array. array_filter keeps the old keys, so the result can have gaps, and array_values() numbers it from 0 again.

To see what an array holds while debugging, print_r($user) shows it in a readable form.
