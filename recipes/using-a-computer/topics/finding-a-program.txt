Finding and starting a program

Search terms: open a program, start a program, find a program, applications menu, start menu, where are the programs, open an app, run a program, AI-2 menu, cannot find a program, application finder, open the file manager.

Written for AI-2. Directed to children, parents and teachers.

WHAT A PROGRAM IS

A program, also called an application or an app, is a set of instructions that does one kind of job: writing, drawing, playing music, searching a Knowledge Pack. To use one, you start it, it opens in a window, and when you have finished you close it.

THE APPLICATIONS MENU

On AI-2 the Applications menu lists the programs you can start. Open it with the button named Applications on the bar, or press Alt and F1 together. The menu shows groups, such as Accessories, Internet or System. Point at a group to see the programs in it, and click a program to start it.

The group named AI-2 holds the programs that belong to AI-2:

- About AI-2 says which version of AI-2 is on the computer.
- Search Knowledge finds the answer to a question in the Knowledge Packs.
- Knowledge Packs shows which Knowledge Packs there are and installs new ones.
- AI-2 Chat (Gopher) opens a chat with the AI that runs on this computer, and keeps your conversations.
- AI-2 Chat (Terminal) is a chat with the same AI in a plain window, the lightest on an older computer.
- AI-2 Chat (Browser) is a chat with the same AI in the web browser, the slowest on an older computer.
- AI-2 Guide explains what this computer can do.
- Software Updates installs updates when the computer is online.

The topic "Asking AI-2 a question" explains Search Knowledge, Knowledge Packs and the chat.

THE BUTTONS ON THE BAR

Some programs also have a small picture on a bar of the screen, so you can start them with one click without opening the menu. On AI-2 a second bar holds pictures for Terminal Emulator, File Manager, Web Browser and Application Finder. It hides itself when a window covers it. If you cannot see it, move the pointer to the edge of the screen where it usually is and wait a moment. File Manager and Web Browser are also in the Applications menu. Hold the pointer still over a picture for a moment and its name appears.

WHEN YOU CANNOT FIND A PROGRAM

1. Look through the groups of the Applications menu. A writing program is usually in Accessories or Office, a drawing program in Graphics. If a group is not in the menu, nothing of that kind is installed yet.
2. Use the Application Finder: press Alt and F3 together, or click its picture on the bar of program pictures. If you see a list of groups, choose All Applications. Type part of the program's name, then double-click the program you want in the results.
3. If it is not there, it may not be installed on this computer. Ask a grown-up. Installing a program needs the computer's password and usually an Internet connection.

STARTING A PROGRAM ONCE

Click once on a program in the menu, then wait. An older computer can take several seconds to open a program, and clicking again only opens a second copy of it. If you are not sure it started, look for its button in the bar.

CLOSING IT

Save your work, then click the cross in the corner of the window. The topic "Windows on the screen" explains the buttons on a window.
